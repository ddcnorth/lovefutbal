# love.fútbol front page prototypes

Design prototypes for a love.fútbol web application: pitch booking, leagues and live activity stats.

- `index.html`: chooser for the options below
- `pitch.html`: front page with a live hand-drawn pitch, booking timetable and league
- `world-clock.html`: front page built on a 24-hour band of site local times
- `live-board.html`: public live display

All sites, teams, fixtures and figures are sample data. These pages are prototypes and are not an official love.fútbol site.

Published at https://proto.amrad.ca/lovefutbal/
